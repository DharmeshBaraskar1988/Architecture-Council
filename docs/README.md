# Plans and designs

Open the `.html` files in any browser (double-click). They need an internet connection only for fonts.

| File | What it is |
|---|---|
| `build-plan.html` | Architecture and implementation plan console: overview, architecture, agents, debate and voting, solutions and trust, Phase 1–4 tabs, decisions |
| `council-room-demo.html` | Clickable demo of the live council room (scripted, sample data) |

These are copies of the published pages. When the plan changes, the published page is updated first
and this folder is refreshed with it. The decision log (D-01 to D-12) is in the Decisions tab of `build-plan.html`.
